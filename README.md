
# Matrix Calculator

Лабораторная работа №3. Матричный калькулятор на C++17.

Индивидуальный вариант №3 — создание единичной матрицы.

## Описание проекта

Программа реализует библиотеку для работы с
динамическими матрицами.

## Реализованные функции

- `create_matrix` — создание матрицы.
- `free_matrix` — освобождение памяти.
- `matrix_add` — сложение матриц.
- `matrix_multiply` — умножение матриц.
- `print_matrix` — вывод матрицы.
- `matrix_from_array` — создание матрицы из массива.
- `matrix_identity` — создание единичной матрицы.

## Сборка и запуск

Требуются CMake и компилятор с поддержкой C++17.

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build
./build/matrix_calculator
```

## Обработка ошибок

В проекте используется механизм исключений C++.

При некорректных размерах матриц, несовместимых
размерах или недопустимых указателях функции
выбрасывают `std::invalid_argument`.

При ошибке выделения памяти может возникнуть
исключение `std::bad_alloc`.

Выделенная память освобождается через `free_matrix`.

## Тестирование

Используется Google Test и CTest.

Проверяются:
- Создание матрицы и заполнение нулями.
- Сложение двух матриц.
- Умножение двух матриц.
- Создание единичной матрицы 3x3.
- Создание единичной матрицы 1x1.
- Некорректные размеры единичной матрицы.
- Некорректные размеры при создании матрицы.
- Несовместимые размеры при сложении.
- Несовместимые размеры при умножении.

Запуск тестов:

```bash
ctest --test-dir build --verbose --output-on-failure
```

Всего реализовано 9 тестов. Все тесты успешно пройдены.

## Проверка памяти

Матрицы:

A = [[1, 2], [3, 4]]
